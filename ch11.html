Chapter 11

Conditions

Is chapter ke baad tum ye kar paoge: program ko faisla lena sikhana: if, elif aur else likhna, aur indentation sahi rakhna.

Ye kyun seekh rahe hain? Login sahi hai ya nahi, marks se grade, game me jeete ya haare, sab faisle conditions se hote hain.

Rasta chunna

Analogy: chauraahe par signal dekhkar tum rukte ho ya chalte ho. Program bhi condition (True ya False) dekhkar rasta chunta hai.

if, elif, else

marks = int(input("Marks: "))
if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 40:
    print("Grade C")
else:
    print("Fail")

Expected output (marks = 80): Grade B

Python upar se neeche condition check karta hai aur pehli True wali jagah ruk jata hai. Baaki ko dekhta bhi nahi. Isliye order matter karta hai: agar pehle marks >= 40 likhte, to 95 marks wale ko bhi Grade C milta.

Indentation hi structure hai

Python me { } nahi hote. Colon (:) ke baad agli lines thodi andar (4 space) likhi jati hain, aur wahi block banta hai.

if True:
    print("Ye if ke andar hai")
    print("Ye bhi andar hai")
print("Ye bahar hai, hamesha chalega")

Tab aur space ko mat milao. Editor me 4 space hi rakho.

Truthy aur Falsy

Python har value ko True ya False ki tarah maan sakta hai. Falsy values: 0, 0.0, "" (khaali string), [], {}, None, False. Baaki sab Truthy hain.

naam = ""
if naam:
    print("Naam mila")
else:
    print("Naam khaali hai")   # ye chalega

Kaam ke patterns

x = 15
print(10 < x < 20)            # True  (chain comparison)
print(x in [5, 15, 25])        # True  (list me hai?)
print("py" in "python")        # True  (string me hai?)
if x % 2 == 0: print("even")
else: print("odd")             # odd

status = "pass" if x >= 10 else "fail"   # chhota if-else, ek line me
print(status)                  # pass

Nested if: if ke andar if. Par bahut zyada ho jaye to and se jodkar chhota karo.

umar = 20
license = True
if umar >= 18 and license:
    print("Gaadi chala sakte ho")

Ek line me jhalak: Python 3.10 se match ... case bhi aata hai, jo bahut saare options me se ek chunne ke kaam aata hai. Abhi bas naam yaad rakho. Pakka seekhna zaroori nahi hai.

Common mistakes
  • if x = 5: likhna. Compare karne ke liye == chahiye.
  • Line ke ant me colon (:) bhool jana.
  • Indentation galat ho to IndentationError aata hai.
  • if x == 1 or 2: likhna. Ye hamesha True rehta hai kyunki 2 alag se truthy hai. Sahi tarika: if x == 1 or x == 2: ya if x in (1, 2):.
  • input() ka jawab (str) ko number se compare karna, jaise "18" >= 18. Ye error deta hai. Pehle int() karo.
  • Ek hi if ke bajaye kai alag if likhna, jisse ek se zyada branch chal jati hain. Ek hi rasta chunna ho to elif use karo.

Khud karo

Easy
  1. Ek number lo aur batao positive hai ya negative.
  2. bool("") aur bool("0") ka jawab kya hoga?
Medium
  1. Marks lekar grade A, B, C ya Fail print karo.
  2. Teen numbers me se sabse bada dhundo (max bina use kiye).
Hint 1Upar se neeche chalne wala if / elif / else likho, bade marks wali condition pehle.
Hint 2if a >= b and a >= c se shuru karo.
Solutionbool("") False hai, bool("0") True hai (kyunki string khaali nahi hai).
if a >= b and a >= c: print(a), elif b >= c: print(b), else: print(c).
Challenge
  1. Leap year checker banao. Saal leap year tab hota hai jab 4 se poora bhaag ho, par 100 se bhaag ho to 400 se bhi hona chahiye. Jaise 2000 leap hai, 1900 nahi.
Checkpoint
  1. elif aur alag-alag if me kya fark hai?
  2. Python me block kaise banta hai?
  3. Kaun si values Falsy hoti hain?

Summary: if / elif / else pehli True condition ka block chalata hai. Colon aur indentation Python ka structure hain. Falsy values (0, khaali string, None) ko pehchano, aur or me har bar poori condition likho.
