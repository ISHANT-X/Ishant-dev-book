Chapter 7

Internet kaise kaam karta hai

Is chapter ke baad tum ye kar paoge: batana ki browser se website tak request kaise jaati hai, aur DNS, HTTP, status code kya hain.

Ye kyun seekh rahe hain? Backend, API aur web ka har kaam isi par khada hai.

Tum client ho (browser ya app) aur website ka computer server. Client maangta hai (request), server jawab deta hai (response).

ShabdMatlab
Internet vs WebInternet network hai, Web uske upar chalne wali websites
IP addressDevice ka pata, jaise 142.250.77.46
DNSNaam (google.com) ko IP me badalne wali contact book

HTTP methods: GET (maangna), POST (bhejna), PUT/PATCH (badalna), DELETE (hatana).

Status codes: 200 sab theek, 301 page shift ho gaya, 400 request galat, 401 login chahiye, 403 allowed nahi, 404 nahi mila, 500 server me gadbad.

APIs isi tarah kaam karti hain: Python code server ko request bhejta hai aur JSON wapas aata hai.

Savdhaan: HTTPS ka lock dikhna ye nahi batata ki site bharosemand hai. Wo sirf connection ko encrypt karta hai. Password ya OTP dalne se pehle site ka naam dhyan se dekho.

Khud karo

Easy

  2. Chrome me F12, Network tab kholo aur page reload karo.
Medium
  1. nslookup google.com chalao aur IP dekho.
  2. Network tab me ek request ka status code dhundo.

Challenge
  1. Ek website ke liye likho ki browser me type karne se page dikhne tak kya-kya hota hai (DNS se response tak).
Checkpoint
  1. DNS ke bina kya dikkat hoti?
  2. Request aur response me kya fark hai?
  3. 404 aur 500 me kiski galti hai?

Summary: Client request bhejta hai, DNS naam ko IP banata hai, server response deta hai. Status code batata hai ki kya hua.
