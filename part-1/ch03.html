Chapter 3

CMD / Terminal

Is chapter ke baad tum ye kar paoge: terminal me folder badalna, files banana aur Python file chalana.

Ye kyun seekh rahe hain? Developers ek line me wo kaam karte hain jo clicks me 10 step leta. Python bhi yahin se chalate hain.

Terminal wo window hai jahan tum computer ko likh ke order dete ho. Uske andar ek program chalta hai, shell, jo tumhari line padhta hai aur OS ko batata hai.

NaamKya hai
TerminalWindow jahan likhte ho
ShellLine samajhne wala program
CMDWindows ka purana shell
PowerShellWindows ka naya, zyada taakatwar shell
C:\Users\Ishant> mkdir python-journey
C:\Users\Ishant> cd python-journey
C:\Users\Ishant\python-journey> dir
C:\Users\Ishant\python-journey> python hello.py
Hello

Line ke aage wala hissa current working directory hai, yaani tum abhi kis folder me ho.

CommandKaam
cd folderFolder ke andar jao
cd ..Ek folder peeche
dirFiles dikhao
mkdir naamNaya folder
clsScreen saaf
python file.pyPython file chalao

Arguments aur flags: command ke aage extra baatein, jaise python --version me --version ek flag hai. Redirect: dir > files.txt output ko file me daal deta hai.

PATH: ye ek list hai jo batati hai ki programs kahan rakhe hain. Isi se python likhte hi Python mil jaata hai.

Savdhaan: internet se mili commands bina samjhe paste mat karo. del aur format jaisi commands files ya poora drive uda sakti hain.

Khud karo

Easy
  1. Start me "cmd" kholo.
  2. dir chalao aur files dekho.
Medium
  1. python-journey folder me cd se jao.
  2. dir > files.txt chalao aur file kholo.
Hint 1Pehle cd Desktop, phir folder ka naam.
Hint 2Redirect ka matlab output ko file me bhejna.
Solutioncd Desktop phir cd python-journey.
Folder me files.txt ban jaati hai jisme list hoti hai.
Challenge
  1. Ek naya folder banao, uske andar jao, wapas aao aur dekho current directory kab badli.
Checkpoint
  1. Terminal aur shell me kya fark hai?
  2. cd .. kya karta hai?
  3. Command paste karne se pehle kya check karoge?

Summary: Terminal window hai, shell command samajhne wala program. cd, dir, mkdir roz ke kaam ki commands hain.
