Chapter 2

Software, OS aur Files

Is chapter ke baad tum ye kar paoge: software aur OS ka kaam batana, aur file, folder aur path sahi se samajhna.

Ye kyun seekh rahe hain? Har program files aur OS ke upar chalta hai. Ye samjhoge to "file nahi mili" jaise errors turant pakad loge.

Hardware wo hai jise haath se chhu sako. Software wo instructions hain jo hardware ko batate hain kya karna hai. Operating System (OS), jaise Windows ya Android, ek manager hai jo sab apps ko hardware baant ke deta hai. OS ka core hissa kernel kehlata hai, jo hardware se seedha baat karta hai.

Jab tum VS Code me file save karte ho, VS Code OS se kehta hai "ye save kar do". OS storage se baat karta hai. Har app yahi tarika use karta hai.

Laptop start hone se Windows tak

Power button dabane par chhota program BIOS/UEFI hardware check karta hai, phir OS ko storage se RAM me laata hai. Isse boot kehte hain.

File, folder aur path

  • File = jaankari ka ek tukda. Folder = files ka dabba.
  • Extension (.py, .txt, .png) file ka type batane ka sanket hai, guarantee nahi.
  • Absolute path = poora pata: C:\Users\Ishant\Desktop\hello.py
  • Relative path = abhi ke folder se pata: practice\hello.py

Permissions: kuch folders (jaise C:\Windows) me badlav ke liye administrator access chahiye. Ye OS ki suraksha hai.

Savdhaan: photo.jpg.exe asal me ek program hai. Ajnabi .exe ya APK mat chalao.

Khud karo

Easy
  1. Explorer me View, Show me File name extensions ON karo.
  2. Desktop pe python-journey folder banao.
Medium
  1. Notepad me print("Hello") likhkar hello.py naam se save karo.
  2. Apni hello.py ka absolute path likho.
Hint 1Save as me type ko All files rakho.
Hint 2File par right click, Copy as path.

Jaise C:\Users\Ishant\Desktop\python-journey\hello.py.

Checkpoint
  1. App aur OS me kya fark hai?
  2. Absolute aur relative path me kya fark hai?
  3. .exe se savdhaan kyun rehna chahiye?

Summary: OS apps aur hardware ke beech manager hai. Path file ka pata hai, aur extension sirf sanket hai.
