Chapter 4

VS Code aur Python kaise milke kaam karte hain

Is chapter ke baad tum ye kar paoge: editor, interpreter aur terminal ka alag-alag kaam batana.

Ye kyun seekh rahe hain? Beginners yahin sabse zyada confuse hote hain. Ye clear ho gaya to baaki aasaan hai.

Teen alag cheezein hain:

VS Code Python nahi chalata. Wo ek smart editor hai jisme code likhte hain. Code Python interpreter chalata hai, jo alag se install hota hai. VS Code bas use bulata hai.

  • IDE vs editor: editor sirf likhne ke liye, IDE me debugger jaise zyada tools bhi hote hain. VS Code editor hai jo extensions se IDE jaisa ban jaata hai.
  • Extension: VS Code me jodne wala chhota software, jaise Python extension. Wo ▶ Run button, autocomplete aur debugger deta hai.
  • Interpreter select karna: VS Code ko batana padta hai ki kaun sa Python use kare.

Roz ka loop

  1. Code likho
  2. Save karo (Ctrl+S)
  3. Chalao (python hello.py ya ▶)
  4. Output padho
  5. Error ho to sudharo

Debugger kya hai

Debugger code ko ek-ek line chalata hai. Breakpoint lagao to code wahin ruk jaata hai aur tum variables dekh sakte ho.

Aam error: 'python' is not recognized. Matlab computer ko Python ka rasta nahi pata. Python dobara install karo aur Add Python to PATH ka tick lagao.

  2. hello.py me apna naam print karwao.
Medium

  2. Jaan-boojh ke pritn likho aur error padho.

Challenge

Checkpoint
  1. Editor, interpreter aur terminal ka kaam alag batao.
  2. Roz ka 5-step loop likho.
  3. "python is not recognized" aaye to kya karoge?

Summary: VS Code likhne ke liye hai, Python chalane ke liye. Dono ka milna ek extension aur sahi interpreter se hota hai.
