VS Code settings aur shortcuts

Is chapter ke baad tum ye kar paoge: VS Code ke zaroori shortcuts aur settings use karna.

Ye kyun seekh rahe hain? Sahi shortcuts se kaam kai guna tez hota hai, aur settings se bekar ki dikkatein nahi aati.

Zaroori settings

  • Auto Save: File menu me Auto Save ON. Save bhoolne ki dikkat khatam.
  • Python interpreter: Ctrl+Shift+P, "Python: Select Interpreter". Run na chale to pehle ye check karo.
  • Formatter: code ko apne aap saaf indentation me rakhta hai.
  • Linter: galtiyan likhte waqt hi laal line se dikha deta hai.
  • Workspace settings: sirf ek project ke liye alag settings.
  • Extensions: sirf zaroori aur verified publisher wale lagao. Zyada extensions VS Code slow karte hain.

Debugger practical

Line ke number ke aage click karke breakpoint lagao, F5 dabao. Step over agli line par, Step into function ke andar, aur Variables panel me values dikhti hain.

Khud karo

Easy
  1. Auto Save ON karo.
  2. Ctrl+` se terminal kholo.
Medium
  1. Ctrl+/ se ek line comment karke dekho.
  2. Ctrl+Shift+P se Select Interpreter kholo.
Hint 1Line par cursor rakho.
Hint 2Command palette me "interpreter" likho.
SolutionLine ke aage # lag jaata hai.
Python versions ki list khulti hai.
Challenge
  1. Ek chhota loop likho, breakpoint lagao aur step over se har round ki value dekho.
Checkpoint
  1. Terminal kholne ka shortcut kya hai?
  2. Run na chale to kaun si setting dekhoge?
  3. Zyada extensions lagana kyun theek nahi?

Summary: Shortcuts, Auto Save, interpreter aur debugger VS Code ko tez aur aasaan banate hain.
