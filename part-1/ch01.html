Chapter 1

Computer kaise kaam karta hai

Is chapter ke baad tum ye kar paoge: computer ke main parts pehchanna, batana ki CPU asal me kya karta hai, aur ek chhota number binary me badalna.

Ye kyun seekh rahe hain? Jab code chalta hai, to wahi parts kaam karte hain. Inhe samjhoge to errors aur slow programs samajhna aasaan ho jaata hai.

Rasoi wali analogy

PartKya karta hai
CPUInstructions chalata hai. Har instruction ke liye 3 kaam: fetch (RAM se uthana), decode (samajhna), execute (karna). Ye ek second me arabon baar hota hai.
RAMTemporary working memory. Jo program abhi chal raha hai, uska data yahan rehta hai. Bijli gayi to saaf.
Storage (SSD/HDD)Files hamesha ke liye. SSD tez hota hai, HDD sasta par slow.
GPUGraphics aur bahut saare chhote calculations ek saath. Games aur AI me kaam aata hai.
MotherboardWo board jis par sab parts judte hain.
Dhyan rakho: Analogy sirf samajhne ke liye hai. Asal me CPU sochta nahi, wo bas instructions ko fetch, decode aur execute karta hai.

Isliye Ctrl+S zaroori hai. Jo file save nahi hui, wo sirf RAM me hai. Save karne se wo storage me chali jaati hai.

Computer sab kuch 0 aur 1 me rakhta hai

Ek bit ya to 0 hota hai ya 1. 8 bits milkar 1 byte. 1 KB = 1024 bytes, 1 MB = 1024 KB, aur aage GB, TB.

Decimal se binary: number ko 2 se baar baar divide karo aur bache hue remainder neeche se upar padho. Example: 13 ÷ 2 = 6 baaki 1, 6 ÷ 2 = 3 baaki 0, 3 ÷ 2 = 1 baaki 1, 1 ÷ 2 = 0 baaki 1. Neeche se upar: 1101. Matlab 13 = 1101.

Text, photo aur audio bhi numbers me badalkar rakhe jaate hain. Jaise letter A ka number 65 hai.

Common mistakes
  • RAM aur storage ko ek samajhna. RAM temporary hai, storage permanent.
  • Binary padhte waqt upar se neeche padhna. Division me remainder neeche se upar padhte hain.

Khud karo

Easy
  1. Ctrl+Shift+Esc dabao (Task Manager) aur apni RAM, CPU, Disk dekho.
  2. Bataao: 8 bits ka kya naam hai?
HintTask Manager ke Performance tab me dekho.
Medium
  1. 10 ko binary me badlo.
  2. Binary 101 ko decimal me badlo.
Hint10 ko 2 se divide karte jao. 101 me positions ki value hai 4, 2, 1.
Solution10 = 1010. 101 = 4 + 0 + 1 = 5.
Challenge
  1. Apne dost ko 1 minute me samjhao ki CPU, RAM aur storage me kya fark hai, bina analogy ke.
Checkpoint
  1. Unsaved file light jaane pe kyun chali jaati hai?
  2. CPU ke 3 kaam kaun se hain?
  3. 13 ka binary kya hai?

Summary: CPU instructions chalata hai, RAM abhi ka kaam rakhta hai, storage hamesha ke liye. Sab kuch andar se 0 aur 1 hai.
