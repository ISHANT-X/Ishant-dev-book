Chapter 5

Python aur VS Code install karna

Is chapter ke baad tum ye kar paoge: Python aur VS Code install karna, aur check karna ki sab sahi chal raha hai.

Ye kyun seekh rahe hain? Galat install sabse badi wajah hai jisse beginners pehle hi din atak jaate hain.

  1. python.org kholo, Downloads me latest Python 3 download karo.
  2. Installer chalao. Sabse pehle neeche wala "Add python.exe to PATH" tick karo, phir Install Now.
  3. CMD kholo aur likho: python --version. Version dikhe to install sahi hai.
  4. code.visualstudio.com se VS Code install karo.
  5. VS Code me Extensions (4 dibbe wala icon) me Python (publisher: Microsoft) install karo.
  6. Folder kholo, hello.py banao, print("Namaste") likho aur ▶ dabao.

Python REPL

Terminal me sirf python likho. Aisa prompt >>> aayega jahan ek-ek line chala sakte ho. Nikalne ke liye exit().

>>> 2 + 3
5

Agar kuch na chale

  • python not recognized: PATH ka tick bhool gaye. Dobara install karo.
  • Purana version dikhe: ek se zyada Python install ho sakte hain. python --version dekho.
  • pip ke liye hamesha python -m pip likhna surakshit hai, taaki sahi Python ka pip chale.

Khud karo

  2. python -m pip --version chalao.

Summary: Official site se install karo, PATH ka tick lagao, aur python --version se check karo.
