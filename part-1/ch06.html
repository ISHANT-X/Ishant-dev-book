Chapter 6

Program andar se kaise chalta hai

Is chapter ke baad tum ye kar paoge: batana ki Python code CPU tak kaise pahunchta hai, aur number ko binary me badalna.

Ye kyun seekh rahe hain? Andar ka flow pata ho to errors aur slow code ki wajah samajh aati hai.

Computer sirf 0 aur 1 (binary) samajhta hai. Tum English jaisa Python likhte ho, to beech me translator chahiye. Wahi Python interpreter hai.

Jab tum python hello.py dabate ho:

  1. Shell OS se Python program start karwata hai.
  2. Python tumhari file storage se RAM me padhta hai.
  3. Code ko pehle bytecode (beech ke chhote instructions) me badalta hai. Ye kabhi .pyc file me __pycache__ folder me rakha jaata hai.
  4. Python Virtual Machine (PVM) bytecode ko ek-ek karke chalata hai, aur CPU kaam karta hai.

Interpreter vs compiler: C jaisi bhasha poora code pehle machine code me badalti hai. Python bytecode banakar usse VM me chalata hai. Isiliye Python likhna aasaan hai par kuch jagah slow ho sakta hai.

Text ke liye har letter ka ek number tay hai. ASCII me English letters hain, Unicode me hindi aur emoji tak. Hexadecimal (base 16) binary ka chhota roop hai, jaise 255 ka hex ff.

Memory: program ke variables RAM me rehte hain. Stack function ke chhote kaam ki jagah hai, heap bade objects ki.
