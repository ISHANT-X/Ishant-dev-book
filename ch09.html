Chapter 9

Print, Variables, Comments aur Data Types

Is chapter ke baad tum ye kar paoge: screen par output dikhana, variable banana, comments likhna aur pehchanna ki koi value kis type ki hai.

Ye kyun seekh rahe hain? Har program data ke saath kaam karta hai. Data ko naam dena (variable) aur uska type samajhna Python ki sabse pehli neev hai.

print() se output

print("Namaste")
print("Ishant", 15)
print("A", "B", "C", sep="-")
print("Hello", end=" ")
print("World")

Expected output:

Namaste
Ishant 15
A-B-C
Hello World

sep batata hai items ke beech kya aaye (default space). end batata hai line ke ant me kya aaye (default nayi line).

Variable kya hai?

Dabba wali analogy: kai log kehte hain variable ek dabba hai jisme value rakhi hai. Ye shuruaat me chal jata hai, par Python me zyada sahi tasveer ye hai: variable ek naam hai jo kisi object ko dikhata hai. Jaise ghar ke bahar naam-patti, jo ghar ki taraf ishara karti hai.

a = 10
b = a            # b bhi usi 10 ko dikhata hai
naam = "Ishant"
print(a, b, naam)

Expected output: 10 10 Ishant

Dhyan do: = ka matlab "barabar hai" nahi, balki "is naam ko is value se jodo" hai.

Naam rakhne ke niyam

  • Letter ya underscore (_) se shuru karo, number se nahi.
  • Space nahi chalta, uski jagah underscore use karo: total_marks.
  • Capital aur small alag mane jate hain: Age aur age do alag naam hain.
  • Python ke khaas shabd (if, for, class) naam nahi ban sakte.
  • Style: chhote letters aur underscore (student_name). Ise snake_case kehte hain.

Comments

# Ye ek comment hai, Python isse chalata nahi
age = 15   # aise line ke baad bhi likh sakte hain

Comment kyun likha hai ye batata hai, sirf wahi nahi jo code already dikha raha hai. Triple quotes ("""...""") function ke docstring ke liye hote hain (Chapter 15 me).

print(type(10))        # <class 'int'>
print(type(3.5))       # <class 'float'>

print(type(True))      # <class 'bool'>
print(type(None))      # <class 'NoneType'>

Dynamic typing: Python me variable ka type pehle se likhna nahi padta. Value ka type hota hai, naam ka nahi. Isliye x = 5 ke baad x = "paanch" likhna allowed hai (par aadat acchi nahi).

Type conversion

print(int("25") + 5)     # 30
print(float("2.5"))      # 2.5
print(str(100) + " rupay")  # 100 rupay
print(int(3.9))          # 3  (dashamlav kat jata hai, round nahi hota)
print(bool(0), bool(""), bool("a"))  # False False True

Python me int kitna bhi bada ho sakta hai (memory ki hadd tak). Par float me thoda sa error aata hai:

print(0.1 + 0.2)   # 0.30000000000000004

Ye Python ki galti nahi, computer me dashamlav number binary me thoda approximate store hote hain. Paise ka hisaab karna ho to baad me decimal module seekhna.

Common mistakes
  • print(Hello) likhna, jabki text ke liye quotes chahiye: print("Hello").
  • 2name = "a", kyunki naam number se shuru nahi hota.
  • "Age: " + 15, kyunki str aur int seedha nahi jud sakte. str(15) ya f-string use karo.
  • Maan lena ki int(3.9) round karke 4 dega. Wo 3 deta hai.
  • Variable ko "dabba" samajhkar b = a ke baad sochna ki a ki value copy ho gayi. Asal me dono naam ek hi object ko dikhate hain.

Khud karo

Easy
  1. Apna naam aur umar do variable me rakho aur print karo.
  2. type(7.0) ka output kya aayega?
Medium
  1. print me sep ka use karke 15-08-2026 jaisi date print karo.
  2. a = 5 aur b = 3 do variable lo aur dono ki jagah badal do (swap).
Hint 1Teen numbers 15, 8, 2026 alag-alag do aur sep="-" lagao.
Hint 2Python me ek line me swap ho sakta hai: a, b = b, a.
Solutionprint(15, 8, 2026, sep="-") deta hai 15-8-2026. Do digit chahiye to "08" string likho.
a, b = b, a ke baad a=3 aur b=5.
Challenge
  1. Teen variable me naam, umar aur sheher rakho. Phir print aur type() se har ek ka type dikhao. Output kuch aisa aaye: naam: Ishant (<class 'str'>).
Checkpoint
  1. Variable asal me kya hai?
  2. int("25") aur int(3.9) kya dete hain?
  3. 0.1 + 0.2 poora 0.3 kyun nahi aata?

Summary: print output dikhata hai. Variable ek naam hai jo object ko dikhata hai. Comment insaan ke liye hota hai. Basic types hain int, float, str, bool aur None, aur type() se pata chal jata hai.
