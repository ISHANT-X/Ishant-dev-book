Chapter 13

Strings

Is chapter ke baad tum ye kar paoge: text ko index aur slice se kaatna, string methods lagana aur f-string se output sajana.

Ye kyun seekh rahe hain? Naam, password, message, file ka text, sab kuch string hai. Isme pakad mazboot to aadha Python aasaan.

String characters ki ek kataar hai. Har character ka ek number (index) hota hai, 0 se shuru.

s = "Ishant"
print(s[0])      # I
print(s[-1])     # t  (peeche se pehla)
print(s[1:4])    # sha  (stop wala shamil nahi)
print(s[::-1])   # tnahsI  (ulta)
print(len(s))    # 6
LetterIshant
Index012345
Negative-6-5-4-3-2-1

Slicing: s[start:stop:step]. Start shamil, stop shamil nahi.

Immutable: string ko badla nahi ja sakta. s[0] = "A" error deta hai. Naya string banana padta hai.

f-string aur escape

naam = "Ishant"
marks = 85.456
print(f"{naam} ke marks {marks:.1f}")   # Ishant ke marks 85.5
print("Line1\nLine2")                   # \n nayi line, \t tab
Common mistakes
  • "Age: " + 20 error deta hai. str(20) ya f-string use karo.
  • Slicing me stop ko shamil samajhna.
  • String badalne ki koshish, jabki wo immutable hai. Method naya string return karta hai, purana nahi badalta.
