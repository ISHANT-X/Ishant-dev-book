Chapter 10

Input aur Operators

Is chapter ke baad tum ye kar paoge: user se value lena, use sahi type me badalna aur arithmetic, comparison aur logical operators ka use karna.

Ye kyun seekh rahe hain? Program tab kaam ka banta hai jab wo user se data le aur us par hisaab ya faisla kare. Input aur operators wahi kaam karte hain.

input() hamesha string deta hai

naam = input("Tumhara naam: ")
print("Namaste", naam)

Expected output (user ne Ishant likha):

Tumhara naam: Ishant
Namaste Ishant

User number type kare tab bhi input() use str hi deta hai. Isliye number chahiye to convert karo.

umar = int(input("Umar: "))
print("Agle saal umar:", umar + 1)

Expected output (user ne 15 likha): Agle saal umar: 16

Agar int() na lagao to "15" + 1 error dega, kyunki str aur int nahi jud sakte. Dashamlav wale number ke liye float(input()) use karo.

10 / 2 ka jawab 5.0 aata hai, 5 nahi. Floor division negative number par bhi "neeche wala" number deta hai: -7 // 2 deta hai -4, -3 nahi.

Modulo ke kaam: even/odd (n % 2 == 0), kisi number se poora bhaag hota hai ya nahi, aur ghante ya din ghumane ke liye.

Comparison operators (jawab hamesha True ya False)

Bahut zaroori: = value ko naam se jodta hai, == do values ko compare karta hai.

Logical operators

umar = 15
print(umar > 10 and umar < 18)   # True  (dono sach hone chahiye)
print(umar < 10 or umar > 12)    # True  (koi ek sach ho)
print(not umar > 10)             # False (ulta kar do)

Assignment operators

score = 10
score += 5     # score = score + 5  -> 15
score -= 3     # 12
score *= 2     # 24

Operator ka order (precedence)

Pehle bracket (), phir **, phir * / // %, phir + -, phir comparison, aur sabse ant me not, and, or. Shak ho to bracket laga do.

print(2 + 3 * 4)     # 14
print((2 + 3) * 4)   # 20

Chhota mini-program

a = float(input("Pehla number: "))
b = float(input("Doosra number: "))
print("Jod:", a + b)
print("Bhaag:", a / b)

Agar b me 0 daala to ZeroDivisionError aayega. Ise sambhalna Chapter 16 me seekhoge.

Common mistakes
  • input() ke jawab ko seedha number ki tarah use karna. "5" + "3" deta hai "53", 8 nahi.
  • = aur == ko mila dena.
  • / se poora number (int) ki ummeed rakhna. Poore number ke liye // use karo.
  • int("3.5") likhna. Ye error deta hai. Pehle float("3.5") karo, phir chahiye to int().
  • and aur or ka order bhool jana. Pehle and chalta hai, phir or.

Challenge
  1. Seconds lo (jaise 3725) aur unhe ghante, minute aur second me badlo. Output: 1 ghanta 2 minute 5 second. (Hint: // aur % dono chahiye.)
Checkpoint
  1. input() kaun sa type return karta hai?
  2. / aur // me kya fark hai?
  3. = aur == me kya fark hai?

Summary: input() hamesha str deta hai, number chahiye to int() ya float(). Arithmetic se hisaab, comparison se True/False, aur and or not se conditions jodte hain. Order yaad na ho to bracket lagao.
