Chapter 11

Conditions

Is chapter ke baad tum ye kar paoge: if, elif aur else likhna, aur and, or, not ke saath condition banana.

Ye kyun seekh rahe hain? Program sirf seedha nahi chalta. Login, game, discount, sab kuch condition se tay hota hai.

Program faisla kaise leta hai?

Rasta chunne ke liye hum condition likhte hain. Condition True ho to ek hissa chalta hai, warna doosra.

marks = int(input("Marks: "))
if marks >= 75:
    print("Distinction")
elif marks >= 33:
    print("Pass")
else:
    print("Fail")

Indentation zaroori hai. Python me andar wale hisse ko 4 space peeche karte hain. Isi se pata chalta hai ki kaun si line kis condition ke andar hai.

Chaining: 0 < x < 10 Python me seedha likh sakte ho. Nested condition ek if ke andar doosra if hota hai, par zyada nesting se code uljhta hai.

Common mistakes
  • if x = 5 likhna. Check ke liye == chahiye.
  • Indentation galat karna.
  • elif ka order galat rakhna: pehle >= 33 likha to 80 marks wale ko bhi sirf "Pass" milega.

Khud karo

Easy
  1. Number lekar batao positive hai ya negative.
  2. True and False ka result?
Medium
  1. Age lekar batao vote de sakte hain ya nahi (18 ya zyada).
  2. Teen number me se sabse bada print karo.
Hint 1if age >= 18 likho.
Hint 2Pehle do ki tulna karo, phir teesre se.
Solutionif age >= 18: print("haan"), else: print("nahi")
m = a, if b > m: m = b, if c > m: m = c, phir print(m)
Challenge
  1. Ek grade calculator banao: marks lekar A, B, C ya Fail do. Marks 0 se 100 ke bahar ho to "galat input" bolo.
Checkpoint
  1. Condition kab True maani jaati hai?
  2. A or B kab False hota hai?
  3. elif ka order kyun matter karta hai?

Summary: if, elif, else se program raasta chunta hai. Indentation se Python samajhta hai kaun si line kiske andar hai.
