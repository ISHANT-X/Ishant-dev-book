Chapter 16

Errors, Debugging aur Exception Handling

Is chapter ke baad tum ye kar paoge: error padhna, try/except se sambhalna aur debugger se bug dhundhna.

Ye kyun seekh rahe hain? Har programmer ke code me error aate hain. Fark ye hai ki acche programmer unhe aaram se padhkar sudharte hain.

Traceback kaise padhein

Traceback (most recent call last):
  File "hello.py", line 3, in <module>
    print(10 / 0)
ZeroDivisionError: division by zero

Neeche se upar padho. Aakhri line batati hai kya hua (ZeroDivisionError), upar wali batati hai kahan (file aur line number).

try, except, else, finally

try:
    n = int(input("Number: "))
    print(10 / n)
except ValueError:
    print("Number likho, text nahi")
except ZeroDivisionError:
    print("Zero se divide nahi hota")
else:
    print("Sab theek chala")
finally:
    print("Ye hamesha chalega")

Specific error pakdo. Sab kuch pakadne wala bina naam ka except: asli bug chhupa deta hai.

def umar(x):
    if x < 0:
        raise ValueError("Umar negative nahi hoti")
    return x
assert umar(5) == 5   # galat ho to AssertionError

Debugging ka tarika

  1. Error ki aakhri line padho.
  2. Line number par jao.
  3. Shak ho to print() se values dekho.
  4. Phir bhi na mile to VS Code debugger me breakpoint lagao aur step over/into se chalo, Variables panel dekhte hue.
Common mistakes
  • Error message ko bina padhe seedha copy karke poochna.
  • Ek saath bahut saari cheezein badalna. Ek-ek badlo aur chalao.
  • Khaali except: pass likhna.

Khud karo

Easy
  1. int("abc") chalao aur error ka naam batao.
  2. Kisi program me jaan-boojh ke ek line galat likho aur traceback padho.
Medium
  1. Ek program likho jo number maange aur galat input par dobara maange (loop + try).
  2. ZeroDivisionError ko pakadkar "zero nahi" print karwao.
Hint 1while True ke andar try lagao.
Hint 2except ZeroDivisionError likho.
Solutionwhile True: try: n = int(input()); break; except ValueError: print("phir se") (har line alag indent me).
try: print(1/0), except ZeroDivisionError: print("zero nahi")
Challenge
  1. Ek chhota calculator banao jo galat input, zero se divide aur galat operator, teeno ko alag-alag message ke saath sambhale.
Checkpoint
  1. Traceback ko kis taraf se padhte hain?
  2. finally kab chalta hai?
  3. Bina naam wala except: kyun kharab hai?

Summary: Error se darna nahi, use padhna hai. Traceback batata hai kya aur kahan. try/except ko specific rakho, aur debugger se line-by-line dekho.
