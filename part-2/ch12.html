Chapter 12

Loops

Is chapter ke baad tum ye kar paoge: for aur while loop likhna, range ko sahi se samajhna aur loop ko line-by-line trace karna.

Ye kyun seekh rahe hain? Baar baar hone wale kaam, jaise list ke har item par kaam ya jab tak sahi input na mile tab tak poochna, loop se hi hote hain.

Loop ki zaroorat

Agar 5 baar "Hello" print karna ho to 5 line likhni padengi. 1000 baar ho to? Loop wahi kaam ek baar likhne par baar baar karwata hai.

for i in range(5):
    print("Hello", i)

range() ko pakka samjho

CodeValues
range(5)0, 1, 2, 3, 4
range(1, 6)1, 2, 3, 4, 5
range(1, 10, 2)1, 3, 5, 7, 9
range(5, 0, -1)5, 4, 3, 2, 1

Yaad rakho: stop wali value shamil nahi hoti.

while loop

count = 1
while count <= 3:
    print(count)
    count = count + 1

Jab tak condition True hai, loop chalta rehta hai. count badhana bhool gaye to infinite loop ban jayega. Rokne ke liye terminal me Ctrl+C dabao.

break, continue, pass

  • break: loop ko turant rok deta hai.
  • continue: is round ko chhodkar agle round par jata hai.
  • pass: kuch nahi karta, bas jagah bharta hai.

Accumulator pattern

total = 0
for n in range(1, 6):
    total = total + n
print(total)   # 15
Common mistakes
  • while me counter badhana bhool jana.
  • range(5) me 5 ko shamil samajhna.
  • Loop ke andar total = 0 likh dena, jisse har round me reset ho jata hai.

Khud karo

Easy
  1. 1 se 10 tak numbers print karo.
  2. range(2, 8) ki values likho.
Medium
  1. 1 se 100 tak ka jod nikalo.
  2. Kisi number ka table (1 se 10) print karo.
Hint 1Accumulator total use karo.
Hint 2for i in range(1, 11) me n * i print karo.
Solutiontotal = 0, for n in range(1, 101): total += n, jawab 5050.
for i in range(1, 11): print(n * i)
Challenge
  1. Number guessing game banao: computer ek number socha hua rakhe aur tum tab tak guess karo jab tak sahi na ho. Har galat guess par "bada" ya "chhota" bataye.
Checkpoint
  1. range(1, 6) me kaun se numbers aate hain?
  2. Infinite loop kaise banta hai aur kaise rokte hain?
  3. break aur continue me fark?

Summary: for tab jab pata ho kitni baar, while tab jab condition par chalna ho. range me stop shamil nahi hota. Tracing table se loop samajhna aasaan hota hai.
