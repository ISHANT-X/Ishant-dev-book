Chapter 9

Print, Variables, Comments aur Data Types

Is chapter ke baad tum ye kar paoge: variable banana, uska type pehchanna aur ek type se doosri type me badalna.

Ye kyun seekh rahe hain? Har program data ke saath kaam karta hai, aur data ko naam dena variable se hi hota hai.

Variable asal me kya hai?

Variable ek naam hai jo kisi value (object) ko refer karta hai. Shuruat me ise "dabba" samajh sakte ho, par asal me naam ek label jaisa hai jo value par chipka hota hai.

naam = "Ishant"
marks = 85
percent = 85.5
pass_hua = True
kuch_nahi = None
print(naam, marks)
TypeMatlabExample
intPoora number85, -3
floatDashmlav wala number85.5
strText"Ishant"
boolSahi ya galatTrue, False
NoneKuch nahi (khaali)None

Type check aur conversion

print(type(marks))      # <class 'int'>
x = int("5")            # text se number
y = str(5)              # number se text
z = float("2.5")

Python me type pehle se likhni nahi padti, value dekhkar apne aap tay hoti hai. Isse dynamic typing kehte hain.

Naam rakhne ke rules

  • Letters, digits aur _ chalte hain, par digit se shuru nahi kar sakte.
  • Capital aur small alag hain: Marks aur marks do alag naam hain.
  • if, for jaise keywords naam nahi ban sakte.
  • Convention: total_marks jaisa snake_case.
Common mistakes
  • "5" + 3 error deta hai, kyunki text aur number nahi jud sakte.
  • = value rakhta hai, == barabar check karta hai.
  • Naam me space ya - daalna.

Khud karo

Easy
  1. naam naam ka variable banao aur print karo.
  2. type(3.5) ka output kya aayega?
Medium
  1. a = 10, b = 3 rakho aur a + b print karo.
  2. "7" ko number banakar usme 3 jodo.
Hint 1Pehle dono variable banao, phir print me jodo.
Hint 2Pehle int() se badlo.
Solutionprint(a + b) deta hai 13.
print(int("7") + 3) deta hai 10.
Challenge
  1. Ek program likho jo apna naam, class aur marks 3 variables me rakhe aur teeno ka type print kare.
Checkpoint
  1. Variable aur value me kya fark hai?
  2. "5" + 3 error kyun deta hai?
  3. = aur == me fark batao.

Summary: Variable ek naam hai jo value ko refer karta hai. Python me type apne aap tay hoti hai, aur int(), str(), float() se type badal sakte hain.
