Chapter 15

Functions

Is chapter ke baad tum ye kar paoge: function banana, arguments dena, value return karwana aur scope samajhna.

Ye kyun seekh rahe hain? Ek hi kaam baar baar likhne ke bajaye ek baar likho aur kahin bhi bulao. Bade programs isi se bante hain.

def add(a, b):
    """Do numbers ka jod return karta hai."""
    return a + b

result = add(3, 4)
print(result)   # 7
  • Parameter function ke naam me likha hota hai (a, b). Argument bulate waqt di gayi value (3, 4).
  • return value wapas deta hai. print sirf screen pe dikhata hai, value wapas nahi karta.
  • Pehli string docstring hai, function ka chhota parichay.

Default aur keyword arguments

def hello(naam, bhasha="Hindi"):
    return f"{naam} bolta hai {bhasha}"

hello("Ishant")                 # default bhasha
hello("Ishant", "English")      # positional
hello(bhasha="Tamil", naam="Ravi")   # keyword, order se farak nahi

Multiple values return: return a, b asal me ek tuple deta hai.

Scope

x = 10            # global
def f():
    x = 5         # local, sirf f ke andar
    return x
print(f(), x)     # 5 10

Function ke andar bane variable function ke bahar nahi dikhte.

Recursion ek jhalak

def factorial(n):
    if n == 1:        # base case: yahan ruk jao
        return 1
    return n * factorial(n - 1)
print(factorial(5))   # 120
Common mistakes
  • return ki jagah print likhna, phir result None aata hai.
  • Function bulana bhool jana (sirf def likhne se kuch nahi chalta).
  • Recursion me base case na likhna.

Khud karo

Easy
  1. Ek function likho jo "Namaste" print kare aur use 3 baar bulao.
  2. Do numbers ka guna return karne wala function likho.
Medium
  1. Ek function banao is_even(n) jo True ya False return kare.
  2. Ek function banao jo list ka sabse bada aur sabse chhota number return kare.
Hint 1Modulo use karo.
Hint 2max() aur min() use karo.
Solutiondef is_even(n): return n % 2 == 0
def hi_lo(L): return max(L), min(L)
Challenge
  1. Ek function likho jo marks ki list le aur average aur grade (A, B, C, Fail) return kare. Alag-alag chhote functions me todo.
Checkpoint
  1. Parameter aur argument me fark?
  2. return aur print me fark?
  3. Local variable function ke bahar kyun nahi dikhta?

Summary: Function reusable code ka dabba hai. Return value deta hai, scope variables ko andar rakhta hai.
