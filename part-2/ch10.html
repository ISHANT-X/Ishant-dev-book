Chapter 10

Input aur Operators

Is chapter ke baad tum ye kar paoge: user se value lena, calculation karna aur comparison likhna.

Ye kyun seekh rahe hain? Calculator se lekar game tak har program user se kuch leta hai aur us par math ya check chalata hai.

Input ka flow

User type karta hai, input() use program tak laata hai, aur hum use variable me rakhte hain.

naam = input("Naam batao: ")
print("Hello", naam)
Dhyan do: input() hamesha text (str) deta hai, chahe tum number hi type karo. Number chahiye to int(input()) likho.
a = int(input("Pehla number: "))
b = int(input("Doosra number: "))
print("Jod:", a + b)

Modulo ka asli use: n % 2 == 0 ho to number even hai.

Comparison aur logical

Comparison: == != > < >= <=. Ye True ya False dete hain. Logical: and, or, not.

Precedence

Pehle **, phir * / // %, phir + -. Shak ho to brackets lagao: (2 + 3) * 4 = 20.

Truthy aur falsy

Ye cheezein False maani jaati hain: 0, "", None, khaali list. Baaki sab True.

Float ka jhol: 0.1 + 0.2 ka result 0.30000000000000004 aata hai. Computer decimals ko binary me approx rakhta hai, isliye floats ko == se compare mat karo.

Khud karo

Easy
  1. input() se naam lekar "Hello, naam" print karo.
  2. 10 % 3 ka result batao.
Medium
  1. Do number lekar unka jod, guna aur // print karo.
  2. Check karo ki koi number even hai ya odd (True/False print karo).
Hint 1Dono ko int(input()) se lo.
Hint 2% 2 == 0 use karo.
Solutionprint(a + b, a * b, a // b)
print(n % 2 == 0) even par True deta hai.
Challenge
  1. Ek mini calculator banao jo do number aur ek operator (+ - * /) le. Zero se divide karne par error na aaye, uska khayal rakho.
Checkpoint
  1. input() hamesha kya return karta hai?
  2. 7 // 2 aur 7 / 2 me fark?
  3. 0.1 + 0.2 == 0.3 kyun False aata hai?

Summary: input() text deta hai, number ke liye int() lagao. // poora hissa deta hai aur % bacha hua. Floats ko barabar check mat karo.
