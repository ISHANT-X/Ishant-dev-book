Chapter 14

List, Tuple, Set, Dictionary

Is chapter ke baad tum ye kar paoge: chaaron collections pehchanna aur batana ki kaun sa kab use karna hai.

Ye kyun seekh rahe hain? Real programs me data ek nahi, bahut saara hota hai. Ye chaar tarike use sambhalte hain.

List: badalne wali, order wali

nums = [3, 1, 2]
nums.append(4)         # [3, 1, 2, 4]
nums.extend([5, 6])    # [3, 1, 2, 4, 5, 6]
nums.insert(0, 9)      # shuru me 9
nums.pop()             # aakhri hatao
nums.remove(1)         # value 1 hatao
nums.sort()            # chhote se bade

append([5,6]) poori list ko ek item banakar jodta hai. extend([5,6]) uske items alag-alag jodta hai.

Copy vs reference: b = a naya list nahi banata, dono ek hi list ke naam hain. b = a.copy() alag copy banata hai.

Tuple: badalne wali nahi

point = (10, 20)
x, y = point      # unpacking: x=10, y=20

Set: sirf alag-alag values

a = {1, 2, 3}
b = {2, 3, 4}
print(a | b)   # {1, 2, 3, 4}  union
print(a & b)   # {2, 3}  common
print(a - b)   # {1}  sirf a me
khaali = set() # khaali set. {} to dictionary hoti hai

Dictionary: key aur value

student = {"naam": "Ishant", "marks": 85}
print(student["naam"])
print(student.get("class", "pata nahi"))   # na ho to default
student["marks"] = 90
for k, v in student.items():
    print(k, v)

student["class"] likhne par key na ho to KeyError aata hai, get() nahi deta.

Khud karo

Easy
  1. List [5, 3, 8] banao aur sabse bada number print karo (max).
  2. Dictionary banao jisme tumhara naam aur class ho.
Medium
  1. [1, 2, 2, 3, 3, 3] se duplicate hatao.
  2. a = [1,2], b = a, b.append(3) ke baad a kya hoga?
Hint 1Set me badlo.
Hint 2Dono ek hi list ko dikhate hain.
Solutionlist(set([1,2,2,3,3,3])) deta hai [1, 2, 3].
a bhi [1, 2, 3] ho jaata hai. Alag chahiye to a.copy().

Checkpoint

Summary: List badalti hai, tuple nahi. Set duplicate hatata hai, dictionary key se value deti hai. Copy aur reference ka fark yaad rakho.
